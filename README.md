# Бюджети участі великих міст України, 2015–2026 — інтерактивний лонгрід

Статична інтерактивна наукова вебстаття (скрол-сторітелінг) про запровадження та
динаміку бюджетів участі (партисипативних бюджетів) у 35 великих містах України
у 2015–2026 роках, їхню частку в міських видатках (131 зіставне спостереження)
та міжнародні орієнтири (Барселона, Париж, Шотландія, Сінгапур, UN-Habitat,
Світовий банк). Без бекенду: HTML + CSS + JavaScript (ES-модулі) + D3.js v7.

## Інтерактивна презентація (`presentation/`)

Окрема сторінка-презентація за чернеткою статті «Бюджети участі у великих містах
України: поширення, верифікація та простежуваність реалізації (2015–2025)»:
<https://kirashchuk.github.io/interactive-pb-article/presentation/>

- 21 слайд: мінімум тексту, підписи до інтерактивних карт і графіків
  (дифузія за роками з відтворенням, картосхема частки й ресурсу на мешканця,
  типологія з фільтром, стан програм після 2022 р., реалізація за джерелами,
  голоси на 1 тис. мешканців, правила конкурсів, деревоподібна діаграма коштів).
- Клік по місту на будь-якій карті відкриває профіль міста.
- Керування: `←`/`→`, `Пробіл`, `Home`/`End`, `O` — зміст, `F` — повний екран,
  `T` — тема; свайпи на сенсорних екранах; якір слайда в адресі (`#dyfuziya`).
- На телефоні слайди йдуть стрічкою з прокручуванням.
- Стиль «картографічного аркуша»: градусна сітка й масштаб на картах,
  шрифти Unbounded / Onest / JetBrains Mono, світла й темна теми.

Дані презентації генеруються з xlsx `Бюджети_участі_2015_2025_статистичні_дані`
(аркуші «Матриця 2015-2025», «Аналітика_частки») і JSON атласу (класи прозорості,
голоси EGAP, картооснова):

```bash
python tools/build_presentation_data.py <шлях до xlsx> <atlas.json>
```

Скрипт звіряє контрольні числа статті (26 981 заявка, 6 207 переможців,
3,07 млрд грн, 113 пар, 161 позиція з трьома показниками) і пише
`presentation/data/deck.json` та `presentation/data/geo.json`.

## Швидкий запуск

Потрібен будь-який статичний вебсервер (сторінка завантажує дані через `fetch`,
тому відкриття файлу як `file://` не працює).

```bash
# з цієї папки (interactive-pb-article/)
python -m http.server 8000
```

і відкрийте <http://localhost:8000>. Альтернативи: `npx serve .`,
`php -S localhost:8000` — будь-який роздавач статики.

## Інтерактив

- **Шкала-слайдер 2015→2021** (зверху) — перетягування або клік по року; підпис
  показує сумарне значення обраного показника за рік. Керується і з клавіатури
  (стрілки на слайдері).
- **Перемикач показника** — сума (грн) / заявки / переможці; синхронізує весь блок.
- **Картодіаграма** (праворуч) — пропорційні бульбашки міст поверх хороплету
  областей (сума показника по містах вибірки). Окремі стани: «немає підтверджених
  даних» (порожнє коло), «до першого циклу» (крапка), «ТОТ» (✕), АР Крим і
  м. Севастополь — штрихування «поза рамкою». Тултипи — і мишею, і фокусом (Tab).
- **Кругова діаграма** — розподіл коштів року між ТОП-6 містами періоду та рештою
  (кольори закріплені за містами, не за рангом).
- **Графіки динаміки** (нижче) — кошти (лінійний), заявки vs переможці
  (стовпчиковий), охоплення міст (area); перехрестя-тултипи; дані доступні також
  таблицею («Переглянути дані таблицею»).

## Як додати авторський текст

Плейсхолдери позначені пунктирними блоками «Слот для тексту»:

- розділи статті — блоки `<div class="slot" data-slot="...">` в `index.html`;
- описи років у лівій колонці інтерактиву — `js/year-texts.js`
  (замініть `placeholder` для відповідного року).

## Перегенерація даних

Основне джерело — Excel-файл «Бюджети_участі_великих_міст_України_2015-2026_
міжнародне_порівняння_2026-07-23.xlsx» у `../Аналітика Бюджетів участі/`
(аркуші «Дані_місто-рік», «Спостереження_частки», «Аналітика_частки»,
«Норми_порівняння», «Аналітичний_поріг»):

```bash
python tools/export_data.py
```

Скрипт перевіряє інваріанти (35 міст, 131 спостереження) і пише
`data/pb_data.json` + `data/analytics.json`.

### Берегова лінія карти статті

`data/ukraine_oblasts.geojson` містить усі 27 українських одиниць ADM1,
включно з АР Крим і Севастополем. Початкові адміністративні полігони
[geoBoundaries UKR ADM1](https://www.geoboundaries.org/) (CC BY 4.0) із
`tools/raw/ukraine_adm1_geoboundaries.geojson` включають морські акваторії.
`tools/build_coastline.py` обрізає лише сім прибережних регіонів
(UA-65, UA-14, UA-23, UA-51, UA-48, UA-43, UA-40) за маскою фізичного суходолу
`presentation/data/geo.json`, поле `land`. Решта 20 геометрій, назви, коди та
прапорці `excluded` залишаються незмінними; статистичні JSON не перезаписуються.

Маска походить із [OpenStreetMap land polygons](https://osmdata.openstreetmap.de/data/land-polygons.html),
© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Обрізаний набір є похідною базою з цією атрибуцією та умовами ODbL;
адміністративне джерело також зберігає атрибуцію geoBoundaries.
Посилання на джерела й метод записані в полі `sources` GeoJSON.
Маска вже округлена до 0,01° (приблизно 1 км), тому це картографічна основа
для оглядової карти, а не точний геодезичний берег. Нові перетини округлено до
п'яти десяткових знаків; це не підвищує точність вихідної маски.

Відтворення з кореня репозиторію (Python 3, Shapely 2.2.0 і Node.js):

```bash
python -m pip install shapely==2.2.0
python tools/build_coastline.py
node scripts/validate-coastline.mjs
npm run build
npm run validate
```

Скрипт відновлює невалідні після округлення полігони маски через `make_valid`,
відкидає залишкові лінії й точки та зберігає валідні Polygon/MultiPolygon.
Зовнішні кільця орієнтовані за годинниковою стрілкою, отвори проти неї,
відповідно до d3-geo. Кожен запуск бере прибережну геометрію із сирого ADM1,
тому повторне генерування не обрізає берег додатково й дає однаковий файл.
Валідатор перевіряє морські точки, усі 35 центрів міст, суходіл Криму та
Севастополя, прапорці, незмінність внутрішніх областей і сферичні площі D3.
Після запуску legacy-експорту `tools/build_data.mjs` повторіть
`python tools/build_coastline.py`, оскільки той експорт відновлює морські межі.

## PDF-версія статті

Стаття доступна і як PDF (`Стаття_Бюджети_участі_2015-2026.pdf`, 13 сторінок) —
той самий аналітичний текст, синхронізований з інтерактивом: графіки, таблиці,
хроніка за роками, **Додаток A з картами України** (річні зрізи 2016/2018/2021/2026
та сумарна карта), **Додаток B — повна таблиця 35 міст** і список джерел.
Перегенерація з актуальних JSON:

```bash
python tools/build_pdf.py
```

Потрібен `reportlab`; шрифт — Times New Roman (Windows). Скрипт читає
`data/pb_data.json`, `data/analytics.json` і `data/ukraine_oblasts.geojson`, тож
спочатку запустіть `export_data.py`, якщо змінилися вихідні дані. Карти малюються
проєкцією Albers у `tools/pdf_map.py` (без matplotlib).

## Методологічні застереження (відображені й у статті)

- Порожня клітинка ≠ нуль: стани «немає підтверджених даних», «до запуску»,
  «призупинено», «не проводився» розрізняються явно.
- Суми мають різні основи (річний ліміт, сума бюджетів переможців, фактичні
  видатки) і не усереднюються між містами; основа показується в тултипі.
- Рамка — 35 міст: 34 міста понад 100 тис. осіб + Сєвєродонецьк (виняток).
  Бердянськ, Маріуполь, Мелітополь, Сєвєродонецьк після 24.02.2022 — ТОТ;
  показники 2022–2026 — документований мінімум за підтвердженими циклами.
- Частка у видатках: знаменник — затверджені річні видатки міста (Open Budget
  API); зіставні лише пари «сума БУ + бюджет міста» одного року.
- Крим і Севастополь — поза рамкою дослідження.

## Доступність і сумісність

Світла/темна теми (системна + ручний перемикач), `aria`-атрибути та керування з
клавіатури, `prefers-reduced-motion`, табличний дублер графіків, `noscript`-фолбек.
Перевірено в сучасних браузерах (Chromium); зовнішніх запитів немає — сайт
повністю автономний.
