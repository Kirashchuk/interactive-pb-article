# ADR-001: Архітектура інтерактивного лонгріда «Бюджети участі 2015–2021»

- **Статус:** прийнято (2026-07-23)
- **Контекст:** потрібна інтерактивна наукова вебстаття (скрол-лонгрід у стилі
  ai-2027.com) з картодіаграмою України, синхронізованим слайдером років і
  графіками динаміки — як підрепозиторій дисертаційного репозиторію, придатна до
  публікації на будь-якому статичному хостингу та до офлайн-перегляду.

## Рішення

1. **Статичний сайт без збірки і без бекенду.** Чистий HTML + CSS + ES-модулі.
   Немає npm-залежностей, бандлера й серверного коду — мінімальні вимоги до
   середовища (будь-який роздавач статики), максимальна довговічність для
   наукового артефакту.
2. **Єдина бібліотека візуалізації — D3.js v7, вендорована локально**
   (`vendor/d3.v7.min.js`). D3 покриває і геопроєкції (конічна рівновелика для
   України), і всі типи графіків; Chart.js не додається, щоб не тягнути другу
   парадигму рендерингу та подвійний розмір. Локальна копія → жодних CDN-запитів,
   працює офлайн.
3. **Дані — окремий етап експорту.** З липня 2026 основний конвеєр —
   `tools/export_data.py` (Python + openpyxl): Excel-файл 2015–2026 з міжнародним
   порівнянням → `data/pb_data.json` + `data/analytics.json`, з перевіркою
   інваріантів (35 міст, 131 зіставне спостереження частки). Семантика
   «порожньо ≠ нуль» кодується явними станами
   (`data / nodata / pre / susp / notheld`), основа суми зберігається для
   тултипів. Legacy-скрипт `tools/build_data.mjs` (CSV-набір 2015–2021)
   залишено для відтворюваності та генерації GeoJSON.
4. **Географія — geoBoundaries UKR ADM1 (simplified), CC BY 4.0**, з двома
   трансформаціями на етапі збірки: округлення координат до 3 знаків (761 КБ →
   425 КБ) і перемотка кілець полігонів (RFC 7946 CCW → d3-geo CW), без якої
   d3 трактує полігони як «весь світ мінус область». Координати міст зашито в
   скрипт збірки (39 сталих точок).
5. **Теми через CSS custom properties.** Кольори візуалізацій задаються лише як
   `var(--…)` у style-властивостях SVG, тому перемикання світла/темна не потребує
   ре-рендера. Палітра — валідована (CVD-перевірки пройдено для обох тем;
   світлі слоти з контрастом <3:1 компенсовано видимими підписами і таблицею).
6. **Анімації деградують коректно:** при `prefers-reduced-motion` або прихованій
   вкладці (rAF не тікає) стани застосовуються миттєво без d3-транзицій.

## Розглянуті альтернативи

- **React/Svelte + бандлер** — відхилено: інтерактив один і локальний, стан —
  два поля (рік, показник); фреймворк додав би збірку та залежності без виграшу.
- **Chart.js для графіків динаміки** — відхилено: D3 вже потрібен для карти,
  одна бібліотека = один стиль осей/тултипів/анімацій.
- **TopoJSON замість GeoJSON** — відхилено: економія ~150 КБ не виправдовує
  додаткову клієнтську бібліотеку; спрощена геометрія ADM1 достатньо легка.
- **Leaflet/MapLibre для карти** — відхилено: потрібна статистична картодіаграма
  з фіксованою проєкцією, а не тайлова інтерактивна карта.

## Наслідки

- Сайт розгортається копіюванням папки; GitHub Pages/Netlify працюють без конфігурації.
- Оновлення даних = перезапуск одного скрипта; контрольні числа ловлять розбіжності.
- Додавання авторських текстів не торкається коду (слоти в HTML і `year-texts.js`).
- Обмеження: без бандлера немає мініфікації власного JS (несуттєво за таких обсягів);
  `fetch` вимагає http-сервера навіть локально (задокументовано в README).
